# Synthetic dataset: October 2026

All vendors, people, and amounts are fictional. Generated by `pnpm dataset` from [`scripts/dataset/scenarios.ts`](../../scripts/dataset/scenarios.ts), which is the place to read or change a scenario. Fixed seed, so a rerun gives the same data; PDF bytes and hashes can change between Chromium versions.

| File | What it is | Used by |
|---|---|---|
| `receipts/` | 40 receipt files: 23 PDF, 14 JPEG phone photos, 3 PNG screenshots | The system (input) |
| `receipts.json` | Intake metadata: submitter, payment source, business purpose, upload order, file hash and pixel size | The system (input) |
| `statement-format-a.csv` | The card and bank statement: signed amounts, `dd/mm/yyyy` | The system (input) |
| `statement-format-b.csv` | The same transactions in a second bank format: debit/credit columns, `02 Oct 2026` dates, other column names | Column-mapping test (Day 3) |
| `ground-truth.json` | Expected fields, category, statement line, match status, exception codes, ledger amount per receipt; canonical statement lines | `pnpm eval` |
| `splits.json` | `tuning` (24) for setting thresholds, `holdout` (16) never looked at while tuning. Stratified so both contain hard cases. | `pnpm eval` |
| `baseline-subset.json` | The 20 receipts used for B0 and B1, with why each was chosen | Baselines |
| `baseline/b0-kit/` | What the Accounting user gets for the timed B0 run: the 20 files, `receipts.csv`, `statement.csv` with line numbers, `answer-sheet.csv`, `INSTRUCTIONS.md` | B0 (human) |

## How the ground truth is written

Every expected status and exception code is written by hand from the scenario's intent in `scenarios.ts`. None of it is computed by `src/core`. If the rules computed the answers, the eval would only check the code against itself.

## Known limits

- One synthetic month, one company, two statement formats.
- TC11 (ambiguous match) has one instance, so it sits in only one split (tuning).
- FX: USD statement lines use a synthetic card-network rate plus a 3% fee. Ground truth asserts the statement's AUD charge as the ledger amount, never a converted rate.
- Stress cases from `06` (unreadable photo, non-receipt, bare "$", ambiguous date, refund, FX outage) are not in this set yet. They are planned for Day 4.
