# 07. Sprint Plan (Monday to Friday, about 8 hours a day)

Each day ends with its **exit criteria** met and `TRACKER.md` updated. If a day runs over, cut from the "If time allows" list first, then ask the human before cutting anything else.

Each day has its own folder in `days/` with that day's focus, the reference sections to read, hour-by-hour blocks, human-only tasks, and exit criteria. Open only the current day's folder while working.

| Day | Focus | Folder | Human-only |
|---|---|---|---|
| 1 (Monday) | Discover, map, and baseline | [`days/day-1-discover-and-baseline/`](days/day-1-discover-and-baseline/README.md) | Interview, confirm rules, timed B0, approve scope |
| 2 (Tuesday) | Design and v0 | [`days/day-2-design-and-v0/`](days/day-2-design-and-v0/README.md) | None |
| 3 (Wednesday) | Working core for a non-developer | [`days/day-3-working-core/`](days/day-3-working-core/README.md) | First unassisted run by the user |
| 4 (Thursday) | Evaluate, break, and harden | [`days/day-4-evaluate-and-harden/`](days/day-4-evaluate-and-harden/README.md) | User feedback session |
| 5 (Friday) | Hand off, prove value, and present | [`days/day-5-handoff-and-present/`](days/day-5-handoff-and-present/README.md) | Record the demo, submit |
